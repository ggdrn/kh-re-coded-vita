# Intro-skip callback regression (v0.0.7)

The v0.0.6 device log (`build/skip-v006/device.log`) reports a prefetch abort
at `0x02068f64`, with `r3=0x02068f65`. This is the DS Thumb entry for
`PollEventTriggerList`, returned as a number by `WaitForEventTriggerActivation`.
EU ov001's relocation at `0x02068f60` and the original ROM disassembly confirm
the target. The task runner must receive the linked Vita function address.

An audit of numeric literals against ov001's EU function symbols also found
`FinishFadeTween` assigning `0x02066ce1` to its return variable. The ROM literal
at `0x02066cdc` targets `StepFadeInTween`. Both replacements live in
`tools/pointer_fixes.py` and are regenerated by `tools/prepare_native_abi.py`.

After building the game VPK, run:

```sh
python3 tools/event_trigger_test/run.py
```

Requires Python Unicorn and a host that permits its JIT. The test executes the
linked ARM functions, mocking only their task/heap services, session-flag lookup,
trigger predicate and fade/audio side effects. It checks initialization, idle
waiting, activation, an empty list, suppression by a session flag, firing once,
deactivation/reactivation, and the fade's returned native callback. It also
checks the VPK archive and that its `eboot.bin` matches the build output.

This is a regression test for the reported invalid jump and related callback;
it does not emulate the complete game or replace an on-device intro-skip test.
